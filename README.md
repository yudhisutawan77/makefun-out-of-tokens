## Entry

> Error: out of tokens mid-sentence. This message was going to explain everything, but it ran out of tokens while explaining—

One line, 123 characters. The error message an AI agent shows when it runs out of tokens mid-sentence — and the message itself dies mid-sentence, exactly like the agent it describes.

## How it works

`main.py` writes the entry text to the output file the grader reads, with no trailing newline. Output resolution order: `ENTRY_OUT` (file or directory) → `MAKEFUN_OUTPUT_DIR` → `/output/entry.txt` → current directory as a last resort.
